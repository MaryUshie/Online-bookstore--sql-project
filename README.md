# Online Bookstore SQL Database Project

## project Overview
This project is an Online Bookstore Database Management System created using MySQL. It demonstrates database design, table relationships, SQL queries, triggers, stored procedures, user privileges, and database backup and restoration.

### Data source 
he dataset used in this project was provided as part of a SQL/MySQL bookstore database assignment.
The database contains four related tables:
Books – book titles, authors, and prices
Customers – customer names, emails, and addresses
Order – customer orders, quantities, and order dates
Payments– payment dates and payment amounts

### Tools
-MySQLDatabase creation, data management, and SQL queries
- MySQL Workbench  Writing, executing, and testing SQL statements
- SQL Data retrieval, filtering, aggregation, joins, triggers, and stored procedures

  ### Data cleaning/Preparation
  
The bookstore data was prepared using SQL in MySQL before analysis.

The following steps were performed:

- Created separate tables for books, customers, orders, and payments.
- Defined primary keys to uniquely identify records.
- Defined foreign keys to establish relationships between the tables.
- Used appropriate data types for each column, including INT, VARCHAR, DECIMAL, and DATE.
- Checked that customer IDs, book IDs, and order IDs correctly matched across related tables.
- Verified that order quantities and payment amounts were recorded correctly.
- Ensured dates were stored in the appropriate DATE format.
- Checked the data for consistency and duplicate records before running queries.
- Used SQL queries to aggregate and analyze the prepared data.
